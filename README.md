# Free Nodes Daily Subscription

每日自动测试并更新的免费代理节点订阅（Clash / Mihomo）。

## 订阅链接（固定不变）

```
https://raw.githubusercontent.com/longyang1233/free-nodes-sub/main/clash.yaml
```

## 使用方法

1. 复制上方订阅链接
2. 在 Clash Verge / Mihomo / FlClash / ClashX 等客户端中「从 URL 添加订阅」
3. 更新订阅后选择节点使用

推荐选择 **♻️ 自动选择** 组，会自动测速选最快节点。

## 更新说明

- 每天凌晨 **01:00（America/Los_Angeles）** 自动执行：
  1. 从 GitHub 公开源拉取数千节点
  2. 通过 `http://www.google.com/generate_204` 实测可用性
  3. 筛选约 50 个当前可用节点并更新本订阅
- 订阅链接永久不变，内容每日刷新
